# MASTER_ROADMAP.md — Master Roadmap: Neon Breakout

> High-level versioning and release roadmap for **Neon Breakout**.

---

## 🟢 V1: MVP Release (COMPLETED)
- Vite 5 + React 18 application framework.
- HTML5 2D Canvas Breakout engine with 60 FPS requestAnimationFrame loop.
- 6 Handcrafted levels including Level 6 Boss Encounter ("THE CORE").
- 7 Power-Up drops (Multi-ball, Lasers, Expand Paddle, Fireball, Magnetic Stick, Energy Shield, Slow-Motion).
- Procedural Web Audio API sound synthesizer.
- Glassmorphic HUD overlay and modal screens (Menu, Level Select, Pause, Game Over, Win).
- Responsive Keyboard, Mouse, and Touch controls.

---

## 🟡 V2: Custom Level Editor & Extra Power-ups (Planned)
- Drag-and-drop brick layout editor.
- Custom level saving to `localStorage` and JSON export/import.
- Additional power-ups (Triple Lasers, Shrink Paddle, Time Freeze).

---

## 🔵 V3: Online Leaderboards & Global High Scores (Planned)
- Serverless backend API integration for global leaderboard tracking.
- Daily and Weekly challenge levels.
